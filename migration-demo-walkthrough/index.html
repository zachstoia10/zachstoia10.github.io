Devin Migration Demo: Walkthrough

Upgrading ZoomInfo's open-source gtm-ai-cli from MCP TypeScript SDK v1 to v2

The situation: The tool depends on an outside building block, the "MCP SDK", to talk to ZoomInfo's AI server. The old version (v1) pulled in 96 third-party packages and had 10 known security warnings, 1 of them critical. Version 2 is smaller and safer, but upgrades are tedious and easy to get subtly wrong.

What Devin did: Devin checked that everything worked before the upgrade, ran the official upgrade tool, fixed by hand what the tool flagged, re-ran every check, and submitted the change for review. Along the way it caught a hidden bug: in v2, the "your login expired" signal moved to a different spot. Without that fix, expired logins would have stopped refreshing, and nothing would have crashed to warn anyone.

Please note: This is a real upgrade, done on a public copy (fork) of the public, MIT-licensed gtm-ai-cli repo. It hasn't been submitted to ZoomInfo. Nothing was deployed, no ZoomInfo system or account was used, and the live tests against ZoomInfo's server weren't run (they need a ZoomInfo login).

What you're looking at

The CLI talks to ZoomInfo's AI server through a library called the MCP TypeScript SDK. Version 2 of that library is split into a smaller, client-only package. Devin ran the upgrade from start to finish: it recorded the "before" checks, ran the official migration tool, fixed what the tool flagged, re-ran every check, and opened a pull request for review. Nothing changes for the person using the CLI.

  4. 4
    The one line that mattered
    PR #5 → src/mcp.ts, line 40 ↗

    In version 2, the HTTP status number (for example 401, "your login expired") moved to a new field. If this line were left as it was, the CLI would never notice an expired login, and auto-refresh would quietly stop working. Nothing would crash, so it's easy to miss.

    - return err instanceof StreamableHTTPError && err.code === 401;
+ return err instanceof SdkHttpError && err.status === 401;

Key takeaways

  • Measured, not claimed. Every check was run before and after, and the numbers come straight from that run.
  • It caught what the tool missed by itself. The migration tool handles the routine work. Devin fixed what it flagged and checked the one change that could silently break logins.
  • Smaller and safer. 80 fewer third-party packages to ship, and no known advisories left.
  • People stay in control. The upgrade arrived as a pull request with green checks for an engineer to review and merge.
